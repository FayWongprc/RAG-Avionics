# 前端 V2 - 标签页布局 + 评估功能

## 🎯 主要改进

### 1. 标签页导航设计
采用清晰的标签页布局，将整个工作流分为5个步骤：

```
① 需求输入 → ② 原子需求 → ③ 测试用例 → ④ 质量评估 → ⑤ 导出报告
```

### 2. 新增质量评估标签页 ⭐
完整集成了四个评估维度：
- **维度1**: 需求覆盖完整度
- **维度2**: 用例结构规范性
- **维度3**: 测试方法与逻辑合理性（支持 LLM 深度评估）
- **维度4**: 追溯链路与证据完整性

### 3. 改进的数据展示
- 折叠/展开功能
- 过滤和搜索
- 统计信息卡片
- 颜色编码（绿色=良好，黄色=警告，红色=问题）


## 📋 使用流程

### 步骤1：需求输入
1. 在文本框中输入需求
2. 可选：点击"显示设置"调整 LLM 和检索参数
3. 点击"开始分析"

### 步骤2：查看原子需求
- 自动切换到"原子需求"标签页
- 查看分解后的原子需求
- 查看领域术语解释
- 查看检索到的证据片段

### 步骤3：查看测试用例
- 切换到"测试用例"标签页
- 可以按测试方法过滤
- 查看详细的测试步骤和预期结果
- 查看设计理由

### 步骤4：质量评估 ⭐ 新功能
1. 切换到"质量评估"标签页
2. 选择是否启用 LLM 深度评估
3. 点击"开始质量评估"
4. 查看四个维度的评估结果：
   - 总览卡片：四个维度的百分比评分
   - 详细问题列表：未覆盖的需求、结构不完整的用例等
   - LLM 评分（如果启用）：每个测试用例的评分和改进建议

### 步骤5：导出报告
- 切换到"导出报告"标签页
- 点击"下载 Excel 文件"
- 获得包含5个工作表的完整追溯矩阵

## 🎨 UI 特性

### 颜色编码
- **绿色**: 良好（覆盖率 ≥ 90%）
- **蓝色**: 正常（覆盖率 ≥ 70%）
- **黄色**: 警告（覆盖率 ≥ 50%）
- **红色**: 问题（覆盖率 < 50%）

### LLM 评分颜色
- **绿色**: 5分（完全符合）
- **蓝色**: 4分（基本符合）
- **黄色**: 3分（部分符合）
- **红色**: 1-2分（不符合）

### 响应式设计
- 支持桌面和平板设备
- 自适应布局
- 移动端优化

## 📊 评估功能详解

### 快速评估（不使用 LLM）
- 执行时间：< 1秒
- 包含维度1、2、4的完整评估
- 维度3只包含静态分析

### 深度评估（使用 LLM）
- 执行时间：取决于测试用例数量（每个用例 1-3 秒）
- 包含所有四个维度的完整评估
- 维度3包含每个测试用例的详细评分和改进建议

### 评估结果展示
1. **总览卡片**: 四个维度的百分比评分，颜色编码
2. **详细分析**: 每个维度的详细统计和问题列表
3. **LLM 评分表**: 按分数排序，低分在前，方便快速定位问题

## 🐛 故障排除

### 标签页无法切换
- 确保已经生成了分析结果
- 只有"需求输入"标签页在没有结果时可用

### 评估失败
- 检查后端是否正常运行
- 检查 LLM API 密钥是否配置正确
- 查看浏览器控制台的错误信息

### 导出失败
- 确保后端 API 正常
- 检查浏览器是否允许下载
